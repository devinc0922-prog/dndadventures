# DnD Adventures

Website for a Claude-led D&D 5e campaign: adventure log, house rules, and browser character sheets for the party.

**Site:** https://devinc0922-prog.github.io/dndadventures/

- Home, adventure log, and house rules are public.
- Character sheets need Google sign-in, and only accounts on the party list can see them. Sheets save as you play and update live for everyone viewing.
- Try a sheet without signing in: [demo](https://devinc0922-prog.github.io/dndadventures/sheet/?demo=sample-fighter).
